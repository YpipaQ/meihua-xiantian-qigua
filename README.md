# 梅花易数 · 先天起卦法

一个**离线可用、零依赖**的梅花易数起卦与解卦工具。
输入两个数字（或一个时间），得到卦象与解读。

> **不需要安装任何东西，不需要联网**。只要电脑上有 Node.js 18+，双击一个脚本就能用。

---

## 这是什么

梅花易数里最核心的一种起卦法：**以数起卦**。
你随口报两个数，程序按古法推出本卦、动爻、之卦、互卦、体用五行，再配上《周易》经文和解卦参考。

它适合：
- 想快速起一卦、看看卦象和断语的人
- 想学梅花易数、对照经文和各家解读的人
- 想要一个**不联网、不上传、结果留在本机**的占卦工具的人

它不适合：
- 想要绝对吉凶断语的人（本项目只给「体用五行关系 + 吉凶分级措辞」，不打包票）
- 想要自动排版成古籍样式的人

## 快速开始

### 第一步：确认有 Node.js

打开终端（Windows 是「命令提示符」或 PowerShell），输入：

```bash
node -v
```

显示 `v18.x` 或更高就行。没有的话去 [nodejs.org](https://nodejs.org/) 装一个长期支持版（LTS）。

### 第二步：启动

**Windows**：双击 `启动演示.cmd`
**Linux / macOS**：双击 `启动演示.sh`，或在终端执行：

```bash
cd 项目目录
./启动演示.sh
```

浏览器会自动打开 `http://127.0.0.1:8642/web/index.html`。
如果没有自动打开，手动把这个地址粘到浏览器里。

> 关掉窗口或按 `Ctrl+C` 就停了。这个服务只监听本机 `127.0.0.1`，局域网内其他电脑访问不到。

### 第三步：起卦

页面有三个入口，**默认是「数字起卦」**——最常用的就是它。

在输入框里填两个数，比如 `12,33`，点「起卦」。

---

## 三种起卦方式

| 方式 | 怎么用 | 适合场景 |
| --- | --- | --- |
| **数字起卦**（推荐） | 填 1 个或多个数字，支持 `12,33`、`12 33`、换行批量粘贴 | 手边有任何数字都能起：报数、页码、车牌、心跳数…… |
| **时间起卦** | 选日期 + 小时（或选时辰） | 想知道「此刻」的卦；日期公历农历都支持 |
| **铜钱摇卦** | 点 6 次，每次模拟掷三枚铜钱 | 传统六爻摇卦，会记录每一爻的掷出结果 |

**数字个数会自动匹配规则**：1 个数（借当前时辰补足）、2 个数、3 个数、4 个及以上，各有对应古法。

## 结果怎么看

默认给你两个东西：**断语**和**经文**。

```
卦意导语：水火相息、变革更新之时。当顺天应人、审时度势，去旧立新……
体用断语：用强而克体，主受制于外、事多掣肘；此际宜静守蓄力、避其锋芒……

经文｜本卦 革（第49卦）卦辞：巳日乃孚，元亨利贞，悔亡。
经文｜初九：巩用黄牛之革。
经文｜之卦 咸（第31卦）卦辞：亨，利贞，取女吉。
```

- **卦意导语**：这一卦整体讲什么
- **体用断语**：用五行生克关系给出倾向（吉/凶/平），并说明理由
- **经文**：本卦卦辞 + 动爻爻辞 + 之卦卦辞

### 想看更多？点「繁」

页面有「简 / 繁」两个按钮：

| 档位 | 包含 |
| --- | --- |
| **简**（默认） | 断语 + 经文，一屏看完 |
| **繁** | 再加：纳甲装卦（八宫/世应/六亲/六神）、详解（名家解读/哲学含义/卦象关联）、六爻断法、十翼（彖传/大象/小象/文言传） |

**功能都在，只是默认不铺满屏幕。** 想看深度的点「繁」即可。

## 常见问题

**Q：双击 `启动演示.cmd` 一闪就没了？**
说明 Node 没装好或不在 PATH 里。先在终端跑 `node -v` 确认。

**Q：浏览器打开是空白 / 报错？**
必须是 `http://127.0.0.1:8642/...`，**不能直接双击 `web/index.html`**——
浏览器出于安全限制，不允许 `file://` 页面读取本地数据文件。

**Q：端口 8642 被占了？**
程序会自动换一个空闲端口，注意看终端里打印的实际地址。

**Q：能不能手机上用？**
服务只监听本机回环地址。若要在同一局域网用手机看，需自行改监听地址（不推荐，见使用手册的安全说明）。

**Q：算得准吗？**
本项目只做两件事：**严格按古法起卦**（算法可复现、有 1100+ 项测试）、**如实呈现卦象与参考文献**。
吉凶判断依赖体用五行关系，属于传统框架内的参考措辞，**不作绝对断言**。

**Q：经文是校对过的吗？**
**没有**。经文库是 AI 初稿 + 多源机器交叉比对（50 卦一致、14 卦有异文），
但**从未人工对照纸质本**。所有异文都留档可查，界面会标注状态（〔未校对〕/〔交叉校验〕）。

**Q：我的使用数据会上传吗？**
不会。这是一个纯本地静态程序，没有任何网络请求、没有统计、没有账号。
