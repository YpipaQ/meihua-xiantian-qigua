## 0. 先选版本：桌面版 还是 网页版

**普通使用 → 用桌面版**（双击就能开，不用装 Node）：

| 系统 | 双击这个 |
| --- | --- |
| Windows | `梅花易数.exe` |
| Linux | `梅花易数` |
| macOS | `梅花易数.app` |

位置在 `dist-desktop/<平台>/梅花易数-<平台>-x64/` 下。第一次拿到时，把**整个文件夹**复制到你想放的地方
（U 盘也行），以后双击即可。**不需要安装，也不需要联网。**

**下面第 1–3 节讲的是网页版启动方式**（开发用/想改代码用）。桌面版直接看第 4 节以后的内容即可——
界面与操作和网页版完全一样。

> 桌面版为什么干净：运行数据全写在自己目录的 `.runtime` 里，退出就删。详见 [§10](#10-安全与隐私)。

## 1. 启动与停止

### 1.1 启动

| 系统 | 操作 |
| --- | --- |
| Windows | 双击 `启动演示.cmd` |
| Linux / macOS | 双击 `启动演示.sh`；或终端 `cd 到项目目录 && ./启动演示.sh` |
| 任意系统（手动） | `node tools/serve.mjs --open` |

启动成功的标志是终端出现：

```
[serve] Meihua Xiantian Qigua demo server started.
[serve] Open:  http://127.0.0.1:8642/web/index.html
[serve] Press Ctrl+C to stop.
```

浏览器会自动打开。没自动开就手动访问上面那个地址。

### 1.2 端口

- 默认 **8642**
- 想换端口：`PORT=9000 node tools/serve.mjs`（Linux/macOS）
  或 `set PORT=9000 && node tools/serve.mjs`（Windows cmd）
- 也可以把端口作为第一个参数：`node tools/serve.mjs 9000`
- **8642 被别的程序占用时**，程序会自动改用随机空闲端口，实际地址看终端输出，别照抄默认地址

### 1.3 停止

在终端按 `Ctrl+C`，或直接关掉那个窗口。
服务是本机进程，关掉即停，不会残留后台任务。

### 1.4 必须走 HTTP 的原因

不要双击 `web/index.html` 直接打开。浏览器对 `file://` 页面有安全限制，
**不允许它读取同目录的 JSON 数据文件**，页面会白屏或报错。
本项目所有数据（卦象、经文、解读）都是独立 JSON 文件，必须经本地 HTTP 服务读取。

## 2. 数字起卦（最常用）

### 2.1 基本用法

1. 点顶部「数字起卦」标签
2. 在输入框填数字
3. 点「起卦」

### 2.2 输入格式

**批量粘贴**支持这三种写法，程序会自动拆成多个输入框：

```
12,33          ← 逗号
12 33          ← 空格
12
33             ← 换行
```

> 从别处复制 `12,33` 粘进去，会自动变成两个输入框，不需要手动点「＋」。

### 2.3 数字个数决定起卦规则

这是梅花易数「以数起卦」的核心：**不同个数走不同的古法**。

| 个数 | 规则 | 说明 |
| --- | --- | --- |
| **1 个** | 一数起卦 | 一个数无法分上下卦，程序借**当前时辰**补足。可以手动指定时辰，留空则取当前 |
| **2 个** | 二数起卦 | 第一个数为上卦，第二个数为下卦，两数之和取动爻 |
| **3 个** | 三数起卦 | 前两数定上下卦，第三数定动爻 |
| **4 个及以上** | 多数起卦 | 对半分组：前一半求和取上卦，后一半求下卦，总和取动爻 |

**对半分组通式**（多数起卦的底层规则）：奇数个时，多出的那个数并入后组。

### 2.4 算法细节（可复现）

所有规则都写在 `data/rules.json`，且每条都有测试锁定。核心运算：

```
上卦数 ÷ 8，余数取卦（余 0 视为 8 = 坤）
下卦数 ÷ 8，余数取卦
动爻数 ÷ 6，余数取爻（余 0 视为 6 = 上爻）
```

**为什么会「余 0 视为 8/6」**：因为八卦/六爻是循环的，整除即回到末位。
这是通行做法，不是本项目自创。

### 2.5 加数 / 减数

点「＋ 加一个数」/「－ 减一个数」可以逐个调整。
减到只剩 1 个数就不能再减（1 个数是合法的最小值）。

## 3. 时间起卦

### 3.1 公历模式（默认）

1. 填日期（用日期控件，范围 1900–2100）
2. 点「今天」可一键取当前日期
3. 选时间：**24 小时制**（填 `14:30`）或 **时辰选择**（选「未时」等，带生肖提示）
4. 下方实时显示换算出的农历与干支
5. 点「起卦」

**自动换算的内容**：农历日期、年干支、月干支、日干支、时辰支。
口径为**立春换年**、**23:00 晚子时自动跨日**（这两点有专门的历法锚点测试，共 24 项）。

### 3.2 农历模式

如果你手上是农历日期：

1. 点「农历（阴历）· 直填」
2. 填农历年份（**可留空**，程序会自动推年支）
3. 选年支（可手动改，与年份二者其一即可）
4. 选农历月、农历日、时辰
5. 点「起卦」

### 3.3 关于闰月

**本程序没有闰月开关**，这是有意的设计。

原因：时间起卦按「当月月数」取数，闰月不另计一个月份序。
也就是说，**勾不勾闰月，起卦结果完全相同**——放一个不影响结果的开关只会让人困惑。
如果你需要精确处理闰月边界，改用「公历 + 24 小时制」自动换算即可。

### 3.4 时间范围限制

内置农历/节气表覆盖 **1900–2100 年**。超出范围不可用（数据本身不支持，不是程序限制）。

## 4. 铜钱摇卦

### 4.1 用法

1. 点「铜钱摇卦」
2. 点「掷第 1 爻」→ 共点 6 次，自下而上（初爻 → 上爻）
3. 每爻掷三枚铜钱

### 4.2 正面约定

默认**「字」为阳面**，这是 `data/coin-config.json` 的配置。
如果你的传统是「背为阳」，改这个配置即可，不需要改代码。

### 4.3 与先天链的区别

**这是两条独立主线**，不要混为一谈：

| | 先天链（时间/数字起卦） | 铜钱链（摇卦） |
| --- | --- | --- |
| 动爻数 | 恒为 1 个 | 0–6 个 |
| 互卦 | 有 | 无 |
| 体用 | 有 | **无**（体用恒空） |
| 断语 | 有 | 无（`verdict` 不装配） |

铜钱摇卦在传统上属于六爻体系，与梅花的体用判断不同源。
本项目**不强行嫁接**——所以铜钱盘不显示体用断语，这不是 bug。

### 4.4 重新起卦

点「重新起卦」清空，从头开始。

## 5. 读懂结果

### 5.1 排盘区

| 字段 | 含义 |
| --- | --- |
| **本卦** | 主卦，代表事情当前状态 |
| **之卦**（变卦） | 动爻变化后的卦，代表发展趋势 |
| **互卦** | 由本卦 2/3/4 爻与 3/4/5 爻组成，代表事情的内在过程（**仅先天链有**） |
| **动爻** | 标 ◉ 的那一爻（或多个），是「变」的触发点 |
| **体 / 用** | 体＝自身（不含动爻的那一卦），用＝对方/事情（含动爻的卦）。**仅先天链有** |

爻画同时给出两种表示：文字爻画（`━━━` / `━ ━`）和卦符（`☰`…），方便对照。

### 5.2 断语区

- **卦意导语**：这一卦整体在讲什么（64 卦各有定稿文案）
- **体用断语**：按五行生克关系给出倾向

体用关系共五种，对应措辞：

| 关系 | 倾向 |
| --- | --- |
| 体克用 | 吉（我能制事） |
| 用生体 | 吉（外来助力） |
| 体用比和 | 平／吉（同气相求） |
| 体生用 | 平偏凶（耗损） |
| 用克体 | 凶（受制于外） |

**静卦**（无动爻）与**多动**（≥2 动爻）时，体用难以唯一确定，程序会如实给提示而不是硬凑。

### 5.3 经文区

- 本卦卦辞
- 动爻爻辞（动几爻列几爻；乾/坤六爻全动则取「用九」/「用六」）
- 之卦卦辞
- 静卦只有卦辞，没有爻辞

经文带**校对状态角标**，含义见 [§8](#8-经文校对状态怎么看)。

### 5.4 演算步骤 / 掷出记录

结果底部有折叠区：
- 先天链：显示「上卦数 ÷8 余…」等完整算式，**可手工核对**
- 铜钱链：显示每一爻的掷出结果

这是为了让你能验算，不是黑箱。

## 6. 简档与繁档

### 6.1 为什么分档

一次占断默认给**断语 + 经文**，一屏看完。
深挖内容（纳甲、详解、十翼）对多数场景是噪音，**所以默认收起，不是没有**。

### 6.2 切换

结果区上方有「简 / 繁」按钮：

| 档位 | 内容 | 大致体量 |
| --- | --- | --- |
| **简**（默认） | 断语 + 经文 | 约 600 字符 |
| **繁** | 追加纳甲装卦、详解（名家/哲学含义/卦象关联）、六爻断法、十翼 | 约 5000 字符 |

切换**不会重新起卦**，当前这一卦原地重渲染。这意味着你可以在同一卦上反复切换视角。

### 6.3 繁档里都有什么

| 区块 | 内容 |
| --- | --- |
| **纳甲装卦** | 京房八宫归属、世应、纳支、六亲、六神、月令旺衰、旬空、月破、应期参考 |
| **详解** | 白话译文、象辞白话、名家详解（断易天机/邵雍/傅佩荣/传统解卦）、哲学含义、卦象关联（互/错/综） |
| **六爻断法** | 世应 + 六亲 + 动变生克参考（仅铜钱盘） |
| **十翼** | 彖传、大象、动爻小象、文言传（仅乾坤） |
| **异文留档** | 经文多源分歧逐条列出（各源写法对照） |

## 8. 经文校对状态怎么看

经文的角标有三种，含义严格区分：

| 角标 | 含义 | 当前数量 |
| --- | --- | --- |
| **（无角标）** | 已人工对照纸质本 | **0 卦** |
| **〔交叉校验〕**（蓝色） | 多个独立来源比对一致（**机器结论**） | 50 卦 |
| **〔未校对〕**（红色） | 未做任何校验 | 14 卦（有异文的卦） |

### 8.1 重要说明

**「交叉校验」不等于「已校对」。**

- 「已校对」= 有人拿纸质书逐字核过 → 本项目**一卦都没有**
- 「交叉校验」= 5 个来源机器比对，结果一致 → 可信度较高，但**仍是机器结论**

所以界面顶部始终有提示条，不会让你误以为已经人工核对过。

### 8.2 异文是什么

14 卦存在多个来源写法不一致的情况（共 19 条），例如「革」卦卦辞第一字：

- 项目现行本：**巳**日乃孚
- 另一份网络语料：**己**日乃孚
- GitHub 电子本：**己**日乃孚

这类「巳/己」「磐/盘」「咷/啕」的差异，程序**不擅自判断谁对谁错**，
而是：正文取现行本，异文全部留档。简档给一行提示「本卦有 N 条多源异文」，
切「繁」可看完整对照。

**这是有意的保守设计**：宁可标「有分歧」，也不假装确定。

## 9. 异常处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击 .cmd 窗口一闪就没 | Node 未装 / 不在 PATH | 终端跑 `node -v` 确认；重装时勾「Add to PATH」 |
| 页面白屏 | 直接双击了 `web/index.html` | 必须经 `http://127.0.0.1:...` 访问 |
| `EADDRINUSE` | 端口被占 | 程序会自动换端口，看终端打印的实际地址 |
| 浏览器没自动打开 | 无 GUI / 无默认浏览器 / 无 `xdg-open` | 手动访问终端打印的 URL |
| 农历日期超出范围 | 内置表覆盖 1900–2100 | 改用范围内的日期 |
| 农历模式没有日干支 | 农历直填无公历日，无法推日干支 | 改用公历模式；或接受六神/旺衰省略的提示 |
| 结果里某个区块缺失 | 缺对应数据文件（可选数据） | 缺文件不阻塞起卦，属于设计内的降级 |

启动脚本会检查 Node 版本（≥18），版本不够会明确报错而不是跑出奇怪结果。

## 10. 安全与隐私

### 10.0 桌面版的「零痕迹」

桌面版是**绿色版**，隐私与干净程度比网页版更进一步：

| 项 | 桌面版行为 |
| --- | --- |
| 系统盘 `~/.config` / `~/.cache`（Windows: `%APPDATA%` / `%LOCALAPPDATA%`） | **不写任何文件** |
| 系统临时目录 `/tmp`（Windows: `%TEMP%`） | **不写任何文件** |
| 注册表 / 开始菜单 / 快捷方式 | **不写、不加** |
| 运行时数据 | 全部写 `<应用目录>/.runtime`，**退出自动删除** |
| 删除程序 | 直接删整个文件夹即可，**无残留** |

**唯一残留场景**：强制结束进程（任务管理器结束任务 / `kill -9`）时清理来不及跑，
`.runtime` 会留在应用目录内 —— 只影响应用自己的目录，不碰系统盘，**下次启动会自动清掉**。

### 10.1 数据不出本机

- 服务只监听 **`127.0.0.1`**（本机回环），**局域网内其他设备访问不到**
- 前端**没有任何网络请求**：不加载 CDN、不调接口、无统计、无账号
- 所有数据都在项目目录里的 JSON 文件

### 10.2 想局域网共享时注意

如果你把监听地址改成 `0.0.0.0` 让手机访问：
- 你的占卦内容会对同网段所有人可见（无鉴权）
- 建议只在可信网络下临时这么做，用完改回

### 10.3 数据文件权限

项目里的 `.json` 都是普通文本，可随意备份。
没有密钥、没有凭据、没有个人身份信息。

## 附：一分钟检查清单

起卦前：
- [ ] 服务已启动，浏览器能打开页面
- [ ] 想好要问什么（梅花讲究「一事一占」，同一件事不要反复起卦）

起卦后：
- [ ] 先看**卦意导语**——整体是什么态势
- [ ] 再看**体用断语**——谁强谁弱
- [ ] 再看**动爻爻辞**——变化的着力点
- [ ] 需要细节再点「繁」
