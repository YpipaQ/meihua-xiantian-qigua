# 先天起卦法 · 规则演示与核对（供人工校验）

> 项目：meihua-xiantian-qigua ｜ 关联：`PLAN.md`、`docs/algorithm-design.md` ｜ 目的：把 5 种首批起卦法的**槽位规则**逐条摆出来并给出完整演算，请你（占法研究者）逐项核对。核对通过后这些规则才锁进 `data/rules.json` 与 `data/cases.json`。
> 说明：本表只核对"如何由数得上下卦与动爻"，不核对卦辞爻辞文字（那是 M1 经文库的事）。

---

## 1. 公共总则（所有方法共用）

1. **先天卦数**：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。
2. **取卦**：某数 ÷8，余数为卦序；**余 0 记 8（坤）**；数不足 8 以本数为卦。
3. **取动爻**：总数 ÷6，余数即动爻位（自下而上 1–6）；**余 0 记 6（上爻）**。
4. **本卦与变卦**：上卦数取上卦、下卦数取下卦 → 查六十四卦得本卦；动爻阳变阴、阴变阳 → 之卦。
5. **序数口径**（时间要素）：年支、时辰均按十二支 子1 丑2 … 亥12（门派差异点做成开关）。

---

## 2. 五种方法 · 规则总表

> 对外入口只分两类：**时间起卦**（本表第 1 行）与**数字起卦**（本表第 2–5 行）——数字起卦由**输入个数**自动选择规则：1 个 → 一数（借时辰）、2 个 → 二数、3 个 → 三数、≥4 个 → 多数；底层 5 条规则记录由程序按个数分派，用户无需感知。

| 方法（现代名） | 输入 | 上卦数 | 下卦数 | 动爻数 | 书内对应/出处锚点 |
|---|---|---|---|---|---|
| **时间起卦法** | 年支 y、农历月 m、日 d、时辰 h | `y+m+d` | `y+m+d+h` | `y+m+d+h` | 观梅占例、牡丹占例（原文口径） |
| **一数起卦法** | 一个数 n（自动补**当下时辰** h） | `n` | `n+h` | `n+h` | 声音起卦：「闻声响，数到几数起作上卦，**加时配数作下卦**，总数除六取动爻」 |
| **二数起卦法** | 两数 n1, n2 | `n1` | `n2` | `n1+n2` | 二字占（第一字上卦、第二字下卦）；丈尺占（丈上、尺下） |
| **三数起卦法**（默认 1\|2） | 三数 n1, n2, n3 | `n1` | `n2+n3` | `n1+n2+n3` | 三字占（姓一字为上卦、名字两字为下卦） |
| **多数起卦法** | k≥2 个数 n1…nk | 前 ⌊k/2⌋ 项之和 | 后 ⌈k/2⌉ 项之和 | 全体之和 | 四字以上字占均分表：4字=2\|2、5字=2\|3、7字=3\|4……11 字以上取一半为上卦 |

> **关键观察（这正是"分总"的依据）**：二数、三数、多数其实是**同一条通式**——把数字序列**对半分**（奇数时上卦取少一半：k=3 → 1|2，k=5 → 2|3）：
> - k=2 → 前1项|后1项 = `n1 | n2` ＝二数法；
> - k=3 → 前1项|后2项 = `n1 | n2+n3` ＝三数法（默认）；
> - k≥4 → 均分 ＝多数法。
> 所以代码里只需**一个"对半分组器"**即可覆盖二/三/多数三种；时间起卦法（按"年/月/日/时辰"语义分组，前 3 项和 | 全和）与一数法（借时辰补足）是另外两种模式。**三条模式 + 一个成卦核**，全部先天以数起卦法都收得住。

## 3. 逐步演算（每步都给数，请逐项核对）

### 3.1 时间起卦法
**例 A（观梅占例）**：辰年(5)、十二月(12)、十七日(17)、申时(9)
| 步骤 | 计算 | 结果 |
|---|---|---|
| 上卦 | (5+12+17)=34 ÷8 余 2 | 兑（泽） |
| 下卦 | 34+9=43 ÷8 余 3 | 离（火） |
| 动爻 | 43 ÷6 余 1 | 初爻动 |
| 本卦 | 上兑下离 | **泽火革 ䷰** |
| 之卦 | 初爻（下卦离初九，阳）变阴 → 下卦成艮 | **泽山咸 ䷞** |

**例 B（牡丹占例）**：巳年(6)、三月(3)、十六日(16)、卯时(4)
| 步骤 | 计算 | 结果 |
|---|---|---|
| 上卦 | (6+3+16)=25 ÷8 余 1 | 乾（天） |
| 下卦 | 25+4=29 ÷8 余 5 | 巽（风） |
| 动爻 | 29 ÷6 余 5 | 五爻动 |
| 本卦 | 上乾下巽 | **天风姤 ䷫** |
| 之卦 | 五爻（上卦乾中爻，阳）变阴 → 上卦成离 | **火风鼎 ䷱** |

> 两例与《梅花易数》原文案例一致 ✅

### 3.2 一数起卦法（借当下时辰补足）
**例**：n=23，当下时辰申(9)
| 步骤 | 计算 | 结果 |
|---|---|---|
| 上卦 | 23 ÷8 余 7 | 艮（山） |
| 下卦 | (23+9)=32 ÷8 余 0 → 记 8 | 坤（地） |
| 动爻 | 32 ÷6 余 2 | 二爻动 |
| 本卦 | 上艮下坤 | **山地剥 ䷖** |
| 之卦 | 二爻（下卦坤六二，阴）变阳 → 下卦成坎 | **山水蒙 ䷃** |

> 规则自检点：① 只给一数时"下卦"从哪来？→ 默认取当下时辰序数参与（口径同"声音起卦加时配数"）。② 若不想自动借时辰，可切换"按静卦提示"（配置开关，见 §5 A1）。

### 3.3 二数起卦法
**例**：(12, 33)
| 步骤 | 计算 | 结果 |
|---|---|---|
| 上卦 | 12 ÷8 余 4 | 震（雷） |
| 下卦 | 33 ÷8 余 1 | 乾（天） |
| 动爻 | (12+33)=45 ÷6 余 3 | 三爻动 |
| 本卦 | 上震下乾 | **雷天大壮 ䷡** |
| 之卦 | 三爻（下卦乾九三，阳）变阴 → 下卦成兑 | **雷泽归妹 ䷵** |

### 3.4 三数起卦法（默认 1|2，书·三字占口径）
**例**：(7, 3, 10)
| 步骤 | 计算 | 结果 |
|---|---|---|
| 上卦 | 第1数 7 ÷8 余 7 | 艮（山） |
| 下卦 | (3+10)=13 ÷8 余 5 | 巽（风） |
| 动爻 | 7+3+10=20 ÷6 余 2 | 二爻动 |
| 本卦 | 上艮下巽 | **山风蛊 ䷑** |
| 之卦 | 二爻（下卦巽九二，阳）变阴 → 下卦成艮 | **艮为山 ䷳** |

**变体对比（若你偏好"前两和为上、末数为下"即 2|1）**：同输入 (7,3,10) →
上=(7+3)=10 ÷8 余 2 兑；下=10 ÷8 余 2 兑；动爻 20÷6 余 2 → 本卦 **兑为泽 ䷹**，之卦 **泽雷随 ䷐**（二爻动）。
> 两条都"规则自洽"，只是分组边界不同。默认取书·三字占口径 1|2，见 §5 A2 请你拍板。

### 3.5 多数起卦法（对半均分）
**例**：(3, 5, 8, 2)，k=4 → 前2项|后2项
| 步骤 | 计算 | 结果 |
|---|---|---|
| 上卦 | 前2项 3+5=8 ÷8 余 0 → 记 8 | 坤（地） |
| 下卦 | 后2项 8+2=10 ÷8 余 2 | 兑（泽） |
| 动爻 | 全和 18 ÷6 余 0 → 记 6 | 上爻动 |
| 本卦 | 上坤下兑 | **地泽临 ䷒** |
| 之卦 | 上爻（上卦坤上六，阴）变阳 → 上卦成艮 | **山泽损 ䷨** |

> 奇数个数示例（k=5，如 (3,5,8,2,7)）：前2项和=8→坤，后3项和=17÷8 余 1→乾，全和 25÷6 余 1 → 本卦 上坤下乾 = 天地否 ䷋（初爻动），与字占"5 字=上 2 下 3"一致。

## 4. 等价性快检（验证"分总"结构成立）

| 检查项 | 结论 |
|---|---|
| 多数通式 k=2 | 前1\|后1 ≡ 二数法公式 → 同输入必同结果 |
| 多数通式 k=3（1\|2） | ≡ 三数法（默认） → 同输入必同结果 |
| 时间起卦法 | 语义分组（年/月/日 vs 时辰），与对半分组**不**同构 → 保留独立规则，不做通式硬套 |
| 一数起卦法 | 借时辰的"补足"特例（缺数补齐），自成一条 |

→ 结论：**成卦核 1 个**；槽位规则收敛为 **3 种分组模式 + 1 个补数策略**；未来字数/声数/物数/笔画等取数器只需把数据喂进同一分组器，不动核心。
