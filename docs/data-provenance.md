## 2. 底本与录入口径

- **卦序/卦名/上下卦构成**：按《周易》通行本（王弼注、孔颖达疏系统）。
- **经文原文**：采用通行本现代标点文本，由 AI 依据通行本知识**初稿生成**。
- **口径约定**（已在 `zhouyi-classic.json` 的 `meta` 中记录）：
  - `guaci` 字段**不重出卦名**（如乾卦辞存"元亨利贞。"，卦名另由 `name` 字段给出）；
  - 爻辞含爻题（初九/六二……上九/上六），乾、坤两卦末尾另附 `用九`、`用六`；
  - 不收录《彖传》《象传》《文言传》等十翼内容（如需按需增补）。
- **字段约定**：
  - `trigrams.json`：`lines` 自下而上，`1`=阳（━━━）、`0`=阴（━ ━）；
  - `hexagrams.json`：`upper`=上卦（外卦）、`lower`=下卦（内卦）；
  - `zhouyi-classic.json`：`yaoCi` 按初爻至上爻排列；
  - **全卦六爻数组约定**：凡组织为六爻数组（算法/展示数据），一律**自下而上**：`[0]=初爻（最下）`、`[5]=上爻（最上）`；动爻位 p(1–6) → 下标 `p−1`（详见 `algorithm-design.md` §2.1）。

## 3. 校对状态

- `proofread: false`（三个文件 meta 中均有标记）。
- **自动校验已通过**（2025 年执行的 PowerShell 脚本）：
  - 数量：八卦 8 / 卦索引 64 / 经文 64，爻目合计 386（384 爻 + 用九 + 用六）；
  - 卦序 1–64 连续、卦名/卦序/卦符/上下卦在文件间交叉一致；
  - 每卦爻题与「爻线阴阳 + 爻位」推导结果一致；用九仅见于乾、用六仅见于坤；
  - 64 个 (上卦, 下卦) 组合无重复；卦符与通行本序码（U+4DC0+order−1）一致。

3. **上下卦构成**：64 卦索引与《易》学资料逐一复核（例如"水雷屯=上坎下震"之类）。
